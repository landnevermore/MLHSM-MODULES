# MLGSM Redesign Prototype

Standalone, static UX prototype for the MLGSM module redesign.

- Cloudflare Pages project: `mlgsm-redesign-preview`
- Branch: `prototype/mlgsm-redesign`
- The dashboard uses mock data only; actions do not control real servers or Docker containers.
- Inspired by Aternos management workflows and Modrinth's clean discovery patterns, without copying either interface.
